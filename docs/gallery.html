Phosphor

The interface system behind Produce Atlas. It renders a late-1970s vector instrument display: emitted light on true black, drawn entirely in stroke, with elevation expressed as brightness rather than shadow. This sheet is the specimen — every component, token and glyph the system ships.

The seven laws

Every decision in the system resolves to one of these. A component that breaks one is wrong even when it looks right.

01
Light is emitted, never reflected.
The ground is true black — an unlit phosphor. Every surface is defined by how much light it emits above that, never by a fill or a tint.
02
Everything is a stroke.
No fills, no radii. A vector display has no fill primitive and cannot cheaply draw a rounded rectangle, so neither does this.
03
Elevation is brightness.
There are no drop shadows. Nothing is above anything else; it is brighter or it is dimmer. Bloom is the only depth cue.
04
Emphasis is luminance, never weight or size.
Six steps: core, hi, base, mid, low, ghost. Bolding a value to make it matter more is not available.
05
Colour is channel, not decoration.
Five phosphors, each with a meaning. You do not mix them for visual interest — you switch channel because the subject changed.
06
The chassis shows its own construction.
Registration marks, tick rules, corner brackets and panel addresses are visible. The instrument does not hide how it is built.
07
Motion is mechanical.
Things step, sweep, snap and type. Nothing eases, springs or cross-fades — a servo does not overshoot for charm, and a vector display cannot dissolve.

Phosphor channels

Five emissive ramps. A container retunes its whole subtree with data-channel; no component knows which phosphor it is being rendered in.

Typography

Five voices. Every piece of text in the system is exactly one of them. No webfonts: the authentic face for an instrument readout is whatever monospace the terminal shipped with, and the display voice is that same face tracked out hard.

Components

Twenty-one components. Each is shown in its resting state; interactive ones respond to hover, focus and keyboard.

Practice

Do

  • Raise luminance to emphasise. Core is the loudest thing available.
  • Switch channel when the subject changes — history to amber, geometry to ice.
  • Print units with every number, and zero-pad every counter.
  • Let modules scroll internally; the chassis holds still.
  • Encode state in shape as well as colour, as the lamps do.
  • Mark a contested figure as contested, on the panel, not in a footnote.

Don't

  • Add a drop shadow. There is no light source and nothing is above anything.
  • Fill a shape, or round a corner. Both are outside the display's vocabulary.
  • Use alarm phosphor for emphasis. It means critical and nothing else.
  • Cross-fade between states. A vector display redraws; it does not dissolve.
  • Run the glitch effect ambiently — a fault that never stops signifies nothing.
  • Bold a value to make it matter more. That is what luminance is for.
