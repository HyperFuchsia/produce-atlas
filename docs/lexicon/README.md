Coined and adopted terms, each with a full dictionary-style entry.

## Entry format

Every entry is one Markdown file named for the headword. An unabridged entry carries
these sections in this order; a concise entry may stop after §6.

1. **Headword block** — syllabification, IPA in more than one variety, respelling,
   stress, part of speech, inflections, coinage date, and an honest attestation check
   ("unattested in X, Y, Z at time of coinage").
2. **Concise definition** — the whole word in one sentence, before it is taken apart.
3. **Sense tree** — numbered senses with lettered subsenses, most central first. State
   plainly how the senses relate; do not leave a reader to infer it. If one sense is the
   *condition* for the others rather than a summary of them, say so.
4. **Etymology** — morpheme by morpheme with source-language forms, carried back to the
   reconstructed root where it is known, with cognate tables. Include a precedent table
   of other English words on the same pattern, and a table of **rejected formations**
   with the reason each failed. Name the one morpheme that carries the distinguishing
   sense, and defend it.
5. **Pronunciation** — variants, and the mis-stressing to warn against.
6. **Inflection and derivation** — the full paradigm with pronunciations, plus related
   and antonymous terms. Name the existing word whose stress pattern the family follows,
   so a reader derives the rest unaided.
7. **Usage** — register, grammar, capitalisation, hyphenation, attributive preference,
   common errors, and at least three citations in running prose. Citations constructed
   for the entry must be **labelled as constructed**.
8. **Synonymy** — a discrimination essay followed by a table stating what each neighbour
   names and what it fails to name. This is where an entry earns its existence; a term
   that cannot be distinguished from its neighbours should not be coined.
9. **Standards, method, tradition, field notes** — how the term is applied, what
   precedent it stands on, and where it sits among existing disciplines.
10. **Equivalents, status, cross-references** — with unverified leads marked as such.

## Adding an entry

Run the [lexopoetic method](./lexopoet.md#the-lexopoetic-method) before writing anything
down. Steps 1, 4 and 5 reject most candidates: if a short phrase already does the job, if
you cannot draw the term's boundary, or if the coinage cannot form a verb and an
adjective, it does not get a file.
