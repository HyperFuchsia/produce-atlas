# Malekind — Health · Integrity · Self-government

**Male Integrity Sustains Human Civilization.**

This repository contains the Malekind website: a long-form editorial platform on male
dignity, whole-person integrity, and bounded self-government, consolidated from the
project's two governing documents —

1. **Whole Man Master Critical Dossier** (22 July 2026) — the current source of truth for
   brand identity, operational state, corrections, membership model, governance, and the
   recommended information architecture.
2. **Institutional Master Framework v2.0** (July 2026) — the deep permanent philosophical
   and institutional content (developed under the earlier working names *Dignivire* and
   *Dignethos*).

Where the two conflict, the dossier's later corrections govern. Redundant passages were
merged into their strongest, most current formulation; nothing substantive was removed.

## The site

Pure static HTML/CSS/JS — no build step, no framework, no external resources, no trackers,
no analytics. Open `index.html` directly or serve the directory with any static host
(GitHub Pages, Vercel, Netlify, `python3 -m http.server`).

Navigation follows the dossier's layered route hierarchy:

| Layer | Pages |
|---|---|
| Start here | `index.html` |
| Understand | `framework.html` + 13 `framework-*.html` pages |
| Apply | `scenarios.html`, `reflect.html` |
| Check in | `check-in.html` (adult, consent-first, browser-only) |
| Find care | `care.html` (crisis resources first, free forever) |
| Verify | `evidence.html` (evidence ladder, claim cards, red-team, corrections, sources) |
| Know your data | `privacy.html` |
| Governance | `governance.html` |
| Membership | `membership.html` (Open Access live; paid tiers accurately closed) |
| Reference | `glossary.html`, `accessibility.html`, `about.html` |

## Design system

Editorial palette (paper, ink, cream, sand, navy, clay, oxblood), serif display type,
sans-serif interface type, ambient "Dignity / Integrity / Sovereignty" background
(decorative, `aria-hidden`, pointer-inert, disabled by OS reduced-motion and by the manual
**Calm mode** toggle), dark mode, skip links, visible focus, reading-progress indicator.
No gamification: no scores, streaks, badges, rankings, or countdowns.

## Honest current state

The site describes itself truthfully per the dossier: a live Open Access editorial beta.
Paid enrollment is closed; the automated AI reviewer is offline; billing, refunds,
community, provider network, and clinical care are **not live** and are labeled that way.

Crisis resources (US: call/text **988**, or **911** in immediate danger) are free on every
page and never gated behind membership, registration, or AI interaction.
